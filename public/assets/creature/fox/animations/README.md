# Mesh2Motion fox animations (OpenNexus3DStudio)

CC0 Mesh2Motion quadruped clips for the creature template rig.

- `fox-animations.glb` — all clips in one GLB (playback source)
- `catalog.json` — UI groups (Locomotion / Idle / Actions / Combat)
- `<group>/<clip>.json` — organized per-clip metadata pointing at the bundle

Clip names: Walk, Run, Sneak, Jump, Fall, Idle, Idle Alert, Sit, Rest Pose, Bark, Bite, Howl, Fetch, Death
